## 🎮 About the Project

A simple and fun Snake game built using Unity. This project is part of a university assignment focused on game development fundamentals and UI design in Unity.

## 🛠 Requirements

To play or modify the game, you will need:

- [Unity Hub](https://unity.com/download)
- Unity Editor (recommendation: version 2020.3 or later)
